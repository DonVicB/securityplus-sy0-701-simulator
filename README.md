# Security+ SY0-701 Practice Simulator

Tablet-first interactive practice simulator for CompTIA Security+ SY0-701 study.

## Included
- 5 practice exams
- 90 questions per exam
- Interactive PBQs with touch/S Pen-friendly controls
- 90-minute timer, flag-for-review, study mode, scoring, and domain breakdown
- Progressive Web App support and offline caching

## Install on Android / Samsung Galaxy Tab
1. Open the GitHub Pages site in Chrome or Samsung Internet.
2. Open the browser menu.
3. Choose **Install app** or **Add to Home screen**.
4. Launch **Security+ SY0-701 Simulator** from the home screen.

This is original practice material based on published SY0-701 objectives. It is not an official CompTIA product and does not contain real exam questions.
